# TypeScript Sandbox

A TypeScript practice environment. Use the `src/playground/` files to experiment with types, functions, generics, classes, and more.

## Run a playground file

```bash
npm run play src/playground/01-types.ts
npm run play src/playground/02-functions.ts
npm run play src/playground/03-interfaces-types.ts
npm run play src/playground/04-generics.ts
npm run play src/playground/05-classes.ts
npm run play src/playground/06-type-narrowing.ts
npm run play src/playground/07-utility-types.ts
```
